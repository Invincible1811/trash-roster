# Hetherington Trash Roster

Weekly trash duty for the house (Favour, Wahab, Tanaka, Bernard), Nov 2026 to Nov 2027.
Pickup is every Friday at 7 a.m.; bins go out Thursday night after 6 p.m.

- Web page: `index.html` (served with GitHub Pages)
- Printable one-page PDF: `Hetherington-Trash-Roster.pdf`
- Phone reminders: `cal/<name>.ics` (one calendar per housemate, alert Thursday 6 PM). Rebuild with `python3 make_calendars.py`.
